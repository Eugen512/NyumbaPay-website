NYUMBAPAY WEBSITE FILES

Files:
- index.html
- styles.css
- script.js
- nyumbapay-mark.svg (alternate vector mark)
- nyumbapay-app-icon.png (your supplied official app icon, used on the site and browser tab)

DEPLOYMENT
Upload these four files to the root of your static website repository or static-site folder. Do not put them inside an extra nested folder unless your hosting setup is configured for it.

DOWNLOAD BUTTONS
All app download buttons use the permanent latest-release URL:
https://github.com/Eugen512/NyumbaPay-Downloads/releases/latest/download/NyumbaPay.apk

To keep the website pointed at the newest version, publish each new APK as a GitHub Release and attach the file with the exact name:
NyumbaPay.apk

This is a static website. No server-side environment variables or build command are required. Set the publish directory to the folder containing index.html if your hosting provider asks for one.

THEME SUPPORT
The website supports both light and dark themes. It initially follows the visitor's system preference and includes a theme toggle in the navigation. The visitor's manual choice is saved in browser local storage.
