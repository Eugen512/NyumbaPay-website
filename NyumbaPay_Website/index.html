QUICK ANSWERS

Before you
step forward.

A few useful things to know before installing NyumbaPay.

How do I install NyumbaPay? ＋
Download the official APK using the button on this website. Open the downloaded file and follow Android's installation prompts. Your device may ask you to allow installation from the browser or file manager you used. Only proceed with a download you obtained from the official NyumbaPay release link.
How does a landlord add tenants? ＋
Set up the property first, create the rooms, then add tenant details and associate the tenant with the relevant room. Tenant access and credentials depend on the account's activation and payment status inside NyumbaPay.
Can a caretaker add a tenant? ＋
Where tenant registration is available to the assigned caretaker role, open the assigned property, select the relevant room, enter the tenant details and save the record. The exact actions depend on the permissions configured for that role. Tenant access and credentials follow the app's activation and payment flow.
Can a caretaker use the landlord's login? ＋
Caretakers should use the caretaker sign-in details assigned to them. Their available actions depend on the role and property access configured for their account.
Does NyumbaPay offer live instant chat? ＋
NyumbaPay focuses on property records, notices and maintenance-related workflows. It is not presented as a general-purpose live-chat app. Use the communication and update features available in your version of NyumbaPay for property-related follow-up.
Is this the official app download? ＋
Yes. The download button links directly to the NyumbaPay Android APK on the NyumbaPay Downloads GitHub release page. Check the link before installing and avoid unofficial copies.
