Ask us a question ↗
Who is NyumbaPay for?+

NyumbaPay is designed for landlords, caretakers, and tenants, with access and features based on each user's role.

How do I get the Android app?+

Use any Download NyumbaPay button on this website to download the latest published Android APK.

How do I install the APK?+

After downloading, open the APK on your Android device and follow the installation prompts. Android may ask you to allow installation from the app or browser you used to download it. Only install apps you trust.

Will the website link change when the app is updated?+

The download button uses the latest-release link. When a newer APK is published as a GitHub release with the filename NyumbaPay.apk, the same website button can direct visitors to that latest release.

How can I get help?+

Email the NyumbaPay team at nyumbapay1@gmail.com and include a short description of your question.
