Helpful details for installing and using NyumbaPay.

How do I install NyumbaPay? ＋
Tap Download NyumbaPay to download the official APK. Open the downloaded file and follow Android's prompts. Depending on your phone, you may need to allow installation from the browser or file manager you used. Only install a file obtained from the official release link.
How does a landlord add a tenant? ＋
Set up the property, create its rooms, then add tenant details and associate the tenant with the relevant room. Tenant access and credentials depend on the activation and payment process in the app.
Can a caretaker use the landlord's login? ＋
No. Caretakers should use their own assigned caretaker credentials. Available tasks depend on the permissions configured for their account.
Does NyumbaPay include live instant chat? ＋
This website does not promise a separate live-chat service. NyumbaPay focuses on property records and the notice and maintenance workflows available in the app. Use the communication features present in your installed version.
Is this the official download? ＋
Yes. The download button links directly to the NyumbaPay APK asset on the NyumbaPay-Downloads GitHub release. The button does not display the raw address as its visible text.
