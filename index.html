A few useful things to know before installing NyumbaPay.

How do I install NyumbaPay? ＋

Download the official APK using the button on this website. Open the downloaded file and follow Android's installation prompts. Your device may ask you to allow installation from the browser or file manager you used. Only install a file obtained from the official release link.

How does a landlord add tenants? ＋

Set up the property first, create its rooms, then add tenant details and associate the tenant with the relevant room. Tenant access and credentials follow NyumbaPay's account activation and payment flow.

Can a caretaker use the landlord's login? ＋

Caretakers should use their own caretaker sign-in details. Available actions depend on the role and property access configured for the account.

Does NyumbaPay offer live instant chat? ＋

This website does not promise a separate live-chat service. NyumbaPay focuses on property records, notices and maintenance-related workflows. Use the communication features actually available in your app version.
